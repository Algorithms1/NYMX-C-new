二、经典书籍（分阶段，适配 Linux C 开发，含 Rocky 适配建议）
2.1 入门筑基阶段（C 语言语法 + Linux 基础，零基础 / 语法复习）
1. 《C Primer Plus（第 6 版）》
    作者：Stephen Prata
    适用人群：C 语言零基础、语法复习
    核心内容：C89/C99/C11 语法、数据类型、指针、数组、函数、文件操作
    Rocky 适配价值：所有代码可直接在 Rocky 10 GCC 下编译，配套练习适配 Linux 环境
    阅读建议：配合 Rocky 10 终端实操，完成每章课后习题

2. 《C 和指针（POINTERS ON C）》
    作者：Kenneth A. Reek
    适用人群：攻克 C 语言核心难点（指针、内存）
    核心内容：指针本质、数组与指针、动态内存、字符串操作
    Rocky 适配价值：Linux C 开发的核心是内存管理，本书是 Linux C 程序员必读书

3. 《Linux 就该这么学（第 3 版）》
    作者：刘遄
    适用人群：Linux 系统基础薄弱，需先掌握 Rocky 操作
    核心内容：Rocky/RHEL 命令行、文件系统、权限、开发工具安装
    适配价值：先搞定 Rocky 10 系统操作，再学 C 语言开发，避免环境阻碍

2.2 进阶精通阶段（Linux 环境下 C 系统编程，核心阶段）
1. 《UNIX 环境高级编程（APUE，第 3 版）》
    作者：W. Richard Stevens / Stephen A. Rago
    称号：Linux C 编程圣经
    核心内容：文件 IO、进程管理、信号、线程、进程间通信（IPC）、信号量、套接字
    Rocky 适配价值：完全适配 Rocky 10 的 glibc 2.39 和 Linux 6.12 内核，所有案例可直接编译运行
    配套资源：APUE 官方源码（https://www.apuebook.com/），可在 Rocky 10 直接编译

2. 《Linux 系统编程（第 2 版）》
    作者：Robert Love
    作者背景：Linux 内核核心开发者
    核心内容：Linux 专属 C 系统调用、内核交互、内存优化、异步 IO
    Rocky 适配价值：贴合 Rocky 作为企业级 Linux 的特性，讲解生产环境下的 C 编程技巧

3. 《Linux/UNIX 系统编程手册（上下册）》
    作者：Michael Kerrisk
    核心内容：比 APUE 更详尽的系统调用解析、POSIX 标准、Linux 特有扩展
    适配价值：Rocky 10 下 C 程序排错、系统级开发的字典级参考书

2.3 高级专项阶段（网络 / 安全 / 性能 / 内核，企业级开发）
1. 《UNIX 网络编程 卷 1：套接字联网 API（第 3 版）》
    作者：W. Richard Stevens
    核心内容：TCP/UDP 套接字编程、IO 多路复用（select/poll/epoll）、Linux 网络 C 开发
    Rocky 适配价值：Rocky 10 作为服务器系统，网络 C 开发是核心岗位技能

2. 《C 专家编程》
    作者：Peter van der Linden
    核心内容：C 语言陷阱、指针误区、内存泄漏、编译链接原理
    适配价值：解决 Rocky 10 下 C 程序的常见 Bug，提升代码质量

3. 《性能之巅：系统、企业与云性能优化》
    作者：Brendan Gregg
    核心内容：Linux 下 C 程序性能分析、perf 工具、火焰图、内存 / CPU 优化
    Rocky 适配价值：搭配 Rocky 10 内置的 perf/valgrind，优化 C 程序性能

4. 《Linux 设备驱动程序（第 3 版）》
    作者：Jonathan Corbet
    核心内容：Linux 内核 C 编程、设备驱动开发
    适配价值：Rocky 10 内核 6.12 的驱动开发进阶材料

二、网站 C 语言参考的核心内容板块（基于 2025 年 3 月最新版）
根据你提供的网页内容，该网站的C reference板块做了清晰的结构化划分，所有内容均围绕 ISO C 标准展开，且适配 Rocky Linux 10 的 GCC 编译环境，核心板块及关键学习 / 使用点如下：

1. Language（C 语言核心语法）
覆盖 C 语言本身的所有基础和高级语法，是语法筑基、排错的核心参考，对应 Rocky Linux 10 下 GCC 编译的语法兼容问题排查，关键内容包括：
    基础概念（Basic concepts）：标识符、作用域、类型系统、内存模型等，是理解 Linux C 内存管理的基础；
    预处理（Preprocessor）：#include/#define/ 条件编译等，适配 Rocky 下多版本 GCC 的预处理规则；
    表达式 / 语句（Expressions/Statements）：运算符优先级、循环 / 分支语句、跳转语句等，解决编译时的语法错误；
    声明 / 初始化（Declaration/Initialization）：变量、函数、指针的声明与初始化，攻克 Linux C 的指针核心难点；
    函数（Functions）：函数原型、参数传递、可变参数函数（Variadic functions），适配 glibc 的可变参数实现（如printf系列）；
    C23 新特性专属：位操作（Bit manipulation）、受检整数算术（Checked integer arithmetic），明确 GCC 14/15 对这些特性的支持情况（Rocky 10 可通过-std=c23启用）。

2. Standard Library（C 标准库）
Rocky Linux 10 开发中使用频率最高的板块，覆盖 ISO C 标准库的所有头文件、函数及接口，与 glibc 2.39 完全兼容，核心子板块包括：
    类型支持（Type support）：stddef.h/stdint.h等头文件的类型定义，适配 Linux 64 位架构（x86_64/aarch64）的类型规范；
    程序工具（Program utilities）：stdlib.h的内存分配（malloc/free）、进程退出（exit）、随机数生成等，是 Linux C 程序的基础；
    诊断库（Diagnostics library）：assert.h/errno.h，适配 Rocky 下的程序错误处理（如系统调用的错误码判断）；
    动态内存管理（Dynamic memory management）：专门讲解malloc/calloc/realloc/free，搭配 Valgrind 调试时可快速查阅内存管理规则；
    字符串库（Strings library）：string.h的字符串操作（strncpy/strcmp等），解决 Linux C 的缓冲区溢出问题（安全编程必备）；
    输入 / 输出库（Input/output library）：stdio.h的文件 IO、控制台 IO，适配 Rocky 的文件系统（如普通文件、设备文件的 IO 操作）；
    数值库（Numerics library）：math.h/complex.h的数学函数，搭配 Rocky 下的-lm编译选项使用；
    日期和时间库（Date and time library）：time.h的时间操作，适配 Linux 的系统时间接口；
    C11 并发支持：Concurrency support library，讲解threads.h的线程接口，与 Rocky 下的 pthread 库互补使用。

3. Compiler Support（编译器支持标注）
适配 Rocky Linux 10 的核心亮点，网站对每个 C 特性、函数、头文件都明确标注支持的编译器及版本（如 GCC 14、Clang 18），例如：
    标注 C23 的nullptr在 GCC 14 中需启用-std=c23 -fexperimental-isoc23；
    标注 C11 的原子操作（Atomic）在 GCC 14 中完全支持，可直接在 Rocky 下使用；
    标注 glibc 对标准库的扩展函数（如asprintf）的支持版本，避免 Rocky 下编译时的 “未定义引用” 错误。

4. Technical Specifications（技术规范）
补充 ISO C 的官方技术扩展规范，如动态内存扩展、浮点扩展等，适配 Rocky Linux 10 下的高性能计算、嵌入式开发等专项场景，是高级 C 开发的参考依据。
5. Null-terminated sequence utilities
专门讲解 C 的空终止字节 / 多字节 / 宽字符序列，适配 Linux 的字符编码（UTF-8）和文件路径处理，解决 Rocky 下的字符串编码问题。

三、Rocky Linux 10 下的专属使用技巧
结合 Rocky Linux 10 的 C 开发环境（GCC 14/15、glibc 2.39、dnf 包管理），该网站的实战使用方法远不止 “查语法”，更是解决编译、调试、优化问题的核心工具，关键技巧如下：
1. 编译前：查标准特性的 GCC 支持情况
开发时若想使用 C23/C17 的新特性，先在网站中查阅该特性的Compiler support，确认 GCC 14/15 的支持方式，例如：
    想使用 C23 的typeof，查阅后得知 GCC 14 需加编译选项-std=c23 -fexperimental-isoc23，直接在 Rocky 下使用该命令编译；
    想使用 C11 的线程库threads.h，查阅后得知 GCC 14 完全支持，编译时加-pthread即可。

2. 编译中：快速排查 “未定义引用”/“头文件缺失”
Rocky 下用 GCC 编译时遇到此类错误，直接在网站搜索函数名，查看函数对应的头文件和库依赖，例如：
    用sqrt函数出现未定义引用：搜索后得知需包含math.h，编译加-lm；
    用pthread_create出现错误：搜索后得知需包含pthread.h，编译加-lpthread。

3. 调试中：查标准库函数的错误处理规则
用 GDB/Valgrind 调试时，快速查阅函数的返回值含义和错误码，例如：
    malloc返回 NULL 的场景、open系统调用的错误码（搭配errno.h）；
    fread/fwrite的返回值判断，解决 Rocky 下的文件 IO 读写错误。

4. 开发中：查 glibc 与 ISO C 标准的兼容细节
Rocky Linux 10 的 glibc 2.39 是 ISO C 标准的实现，但有部分扩展函数，网站会标注 **“该函数为 POSIX 扩展，非 ISO C 标准”**，例如getpid/fork（系统调用封装），明确这些函数的使用场景和头文件（unistd.h）

5. 离线部署：适配 Rocky 企业级离线开发
若 Rocky Linux 10 开发环境无网络，可下载网站的离线归档包（2019 年至今持续更新），本地部署后通过浏览器查阅，步骤如下：

# 解压
